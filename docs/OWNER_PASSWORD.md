# 사장님 6자리 비밀번호

## 초기값과 변경

- 별도 저장값과 `STUDIO_OWNER_PASSWORD_HASH`가 모두 없으면 초기값은 `000000`이다.
- 초기값은 명시적 Development/Test Demo에서 로그인할 수 있다. 실제 운영에서는 초기값으로 예약정보에 접근할 수 없으며 총관리자의 설정을 안내한다.
- 총관리자 `/master-control` → **사장님 비밀번호** → 새 숫자 6자리와 확인 입력 → 저장.
- `000000`은 새 비밀번호로 저장할 수 없다. 저장된 비밀번호 자체는 다시 보여주지 않는다.
- 현재 배포의 업체 한 곳을 대상으로 한다. 다른 업체 배포의 총관리자에서 다른 값을 설정한다. 여러 업체를 한 화면에서 관리하는 멀티테넌트 기능은 없다.

## 우선순위와 저장

1. 총관리자가 저장한 업체별 비밀번호
2. 기존 배포의 `STUDIO_OWNER_PASSWORD_HASH`
3. 미설정 초기값

Production은 서명된 GAS 요청을 통해 Script Properties의 업체별 비공개 인증 영역에 scrypt hash를 저장한다. Demo는 기존 비공개 Demo 저장소를 사용한다. 평문 비밀번호를 환경변수·Git·계약·상품 설정·Snapshot에 저장하지 않는다. 총관리자 응답은 설정 여부, 출처와 인증 revision만 반환한다.

비밀번호 변경은 Business revision을 올리지 않는다. 과거 설정 복구로 비밀번호가 되돌아가지 않는다. 별도의 인증 revision으로 동시 변경을 충돌 처리한다. 기존 Owner 세션은 폐기하고, 변경 전 revision으로 진행 중이던 로그인도 거부한다. Master 세션에는 영향을 주지 않는다.

## 배포 순서

1. 전용 GAS에 최신 `Code.gs` 반영. 기존 운영 GAS에 무단 적용하지 않는다.
2. 독립된 Master 비밀번호 hash와 기존 필수 환경변수를 설정한다.
3. 총관리자로 로그인해 업체별 Owner 비밀번호를 저장한다.
4. 고객 화면 로고 5회 → 사장님 로그인에서 새 비밀번호로 확인한다.

GAS 통신·저장 오류 시 초기값으로 전환하지 않는다. `000000`은 공개된 초기값이므로 실제 고객정보 접근용 공통 비밀번호로 배포하지 않는다.
